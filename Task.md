Цель: Сделать микросервис, который берет текстовый запрос юзера и за миллисекунды понимает, к какому из 50–100 действий системы он относится.
Что нужно сделать:
1. Найти готовую SOTA open-source embedding-модель(наподобие JEV).
 • Обязательно мощная поддержка казахского, русского и английского языков (смотри в сторону BAAI/bge-m3 или intfloat/multilingual-e5-large).
2. Собрать тестовый датасет:
 • Список из 50 разных действий (эндпоинтов) системы с описанием.
 • Набор тестовых фраз от юзеров на трех языках (по 2–3 примера на действие): на русском, английском и обязательно на казахском (с опечатками и сленгом).
3. Реализовать логику классификации:
 • Запрос переводится в вектор → считается косинусное сходство с векторами 50 действий → выдается топ-1 совпадение.
 • Если уверенность меньше условных 60% — выдавать флаг unknown (не уверен).
4. Замерить метрики:
 • Точность (Accuracy): сколько казахских и русских запросов попали в правильный эндпоинт.
 • Скорость (Latency): сколько миллисекунд уходит на один запрос.
5. Обернуть в FastAPI:
 • Вход: JSON {"query": "маған өткен айдың есебін жіберші"}
 • Выход: JSON {"endpoint": "get_monthly_report", "confidence": 0.92}
